# ProjectBridge v0.1.1

修复 ChatGPT 可写委派在 Codex 中没有历史会话，以及授权状态与实际目录写权限不一致的问题。

- 可写任务保存 Codex 会话和工具历史，标题以 `ChatGPT` 开头，并返回会话链接。
- 跨端消息添加 `|from_chatgpt|:` / `|from_codex|:` 来源标识。
- 每次启动可写任务前，在同一 Codex 沙盒内实际创建、读取和删除探测文件；失败时直接报告 `workspace_write_unavailable`，不启动模型任务。
- 启动配置不再继承全局额外可写目录；thread/turn/command 的权限参数统一受本地项目授权约束。
- 状态响应保留失败命令和文件操作，明确 `completed` 仅表示轮次结束。

限制：本次不自动修改 Windows 目录 ACL、不提升权限。若目录仍被 Windows 沙盒拒绝写入，需在本机 Codex 中完成该目录的沙盒设置，或选择当前用户拥有的目录。v0.1.0 的临时会话无法恢复。

升级：退出旧版，解压新包并运行 `ProjectBridge.exe`。项目与连接配置沿用原用户数据目录。新旧包可分别保留，勿同时运行。

验证：完整本地测试、真实 App Server 目录写入与越界拒绝、真实模型修改与回读、持久会话读取。ChatGPT 网页账号侧重新连接后的点击验收另行进行。
