# ProjectBridge v0.1.2

简化首次使用流程，并加入新版本提示。

- 首次设置改为“快速体验（推荐首次使用）/ 长期使用（固定入口）”两种连接方式，向导只保留一套 ChatGPT 插件添加引导。
- 项目页新增“第一次使用 ProjectBridge”任务卡：连接、添加项目、复制项目验证提示词；ChatGPT 实际列出项目根目录后自动完成并隐藏。
- 移除向导中已隐藏的旧手工 OAuth 面板和 Cloudflare 固定域名入口。
- 启动时检查 GitHub 最新正式版本，有新版在窗口顶部提示下载；离线时静默跳过。可在“设置 → 更新”中关闭。
- 发布包不再包含调试符号文件，并附 SHA256 校验值。

升级：退出旧版，解压新包覆盖原目录或放到新目录后运行 `ProjectBridge.exe`。项目与连接配置沿用原用户数据目录。

验证：完整本地构建与测试（266 通过，2 个真实环境测试跳过）；发布脚本解压校验 C2C 与协作助手可启动。更新检查已核对 GitHub Releases 接口返回格式。
