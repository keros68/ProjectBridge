# ProjectBridge v0.1.7

更新检查更及时、更可靠。

- 设置 → 更新新增“检查更新”按钮，直接显示结果（已是最新 / 发现新版本 / 检查失败原因）。
- 程序在托盘运行期间每 6 小时自动检查一次，不再只在启动时检查。
- GitHub API 不可达或限流时，改从发布页跳转地址获取最新版本，国内网络下更稳定。
- 每次检查结果写入日志。

升级：0.1.5 及以上在程序顶部点“立即更新”；更早版本运行新的 `ProjectBridge-Setup.exe`。

验证：完整本地构建与测试（273 通过，2 个真实环境测试跳过）；本机实测 API 与发布页跳转两条检查路径；安装、组件启动与卸载验证。0.1.5 → 0.1.6 的程序内一键更新已实测完成（下载、校验、退出、安装、自动重启约 20 秒）。
