# ProjectBridge v0.1.6

安装包体积减小约四成。

- 安装程序 125 MB → 75 MB，免安装压缩包 173 MB → 101 MB，安装后占用 419 MB → 235 MB。
- 主程序、Codex 启动组件和本地协作助手改为共用一份 .NET 运行时（此前三个程序各自内置一份）。
- 只保留中文界面资源；Transceiver 只保留对应 Windows 架构的预编译原生模块（见其 SOURCE-INFO）。
- 功能无变化。

升级：0.1.5 可在程序顶部点“立即更新”；更早版本运行新的 `ProjectBridge-Setup.exe`。项目与连接配置沿用原用户数据目录。

验证：发布包解压校验、安装后 C2C / 协作助手 / Transceiver 原生模块加载、卸载验证；新目录结构下主程序启动与退出正常。
