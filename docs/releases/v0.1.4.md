# ProjectBridge v0.1.4

YOLO 改为默认开启，并整理界面样式与对齐问题。

- YOLO 默认开启：网页连接验证后，对已授权网页读取的项目直接应用网页修改，授权自动续期，断开或退出时收回。在“编辑”页取消勾选可为单个项目改回逐次本机确认，该选择按项目保存。每次写入前仍自动备份，可在“待处理修改”中恢复。
- 移除 YOLO 有效期下拉框（修复其与标签重叠的错位）。
- 标签页改为扁平样式；顶部连接状态圆点与状态文字对齐；列表中过长的条目以省略号显示，悬停可看全文。
- 设置向导：运行密钥输入框与其他输入框高度一致，整理说明文字。

升级：运行新的 `ProjectBridge-Setup.exe`；免安装版解压覆盖原目录。项目与连接配置沿用原用户数据目录。

验证：完整本地构建与测试（267 通过，2 个真实环境测试跳过），各页面渲染截图检查；安装程序实际静默安装、组件启动与卸载验证。
