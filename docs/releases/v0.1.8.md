# ProjectBridge v0.1.8

修复统一网关（Secure Tunnel）连接失败后无法恢复的问题。

- 上次连接中途失败或程序异常退出后，残留的隧道记录不再阻止重新连接。
- 连接失败但隧道进程已部分启动时，断开会正确停止该进程。
- 缺少内置 `tunnel-client.exe` 时，提示重新安装或完整解压免安装包（保留 runtime 文件夹）。
- 发布包与免安装包在打包时校验 tunnel-client 可以启动。

升级：0.1.5 及以上在程序顶部点“立即更新”；更早版本运行新的 `ProjectBridge-Setup.exe`。

验证：完整本地构建与测试（285 通过，2 个真实环境测试跳过）；实测 tunnel-client v0.0.13 对未知别名的报错与匹配规则一致；发布包与免安装包解压后 tunnel-client、C2C、协作助手启动校验。
