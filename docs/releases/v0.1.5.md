# ProjectBridge v0.1.5

新增一键更新。

- 有新版本时，顶部提示提供“立即更新”：程序下载安装程序并核对 SHA256，校验通过后自动退出、静默安装到当前程序目录并重新启动。免安装版也会原地升级。
- 下载失败或校验不通过时丢弃文件、保留旧版，可点“查看更新说明”手动下载。
- 更新期间连接会断开一次；开启“启动后自动连接”时，新版启动后自动重连。

升级：本版本需手动安装一次（运行 `ProjectBridge-Setup.exe`，或解压免安装版覆盖原目录）；此后的版本可在程序内一键更新。项目与连接配置沿用原用户数据目录。

验证：完整本地构建与测试（271 通过，2 个真实环境测试跳过）；以程序内相同参数运行安装程序，从 0.1.4 升级到 0.1.5 并自动重启；安装、组件启动与卸载验证。程序内点击“立即更新”到重启的完整链路将在下一版本发布时首次实测。
