# ProjectBridge v0.1.3

新增 Windows 安装程序，并修复项目目录移动后设置无法保存的问题。

- 新增 `ProjectBridge-Setup.exe`：安装到当前用户目录，无需管理员权限，创建开始菜单快捷方式，可在“应用和功能”中卸载。卸载时保留项目与连接设置。免安装版 `ProjectBridge.zip` 继续提供。
- 修复：已登记项目的目录被移动或删除后，所有设置保存都会失败并提示“项目设置未保存”。现在该项目按不可用处理，不影响其他项目。

升级：运行新的 `ProjectBridge-Setup.exe`；免安装版解压覆盖原目录。项目与连接配置沿用原用户数据目录。从免安装版改用安装版时，可删除旧的解压目录。

验证：完整本地构建与测试（267 通过，2 个真实环境测试跳过），新增目录移动回归测试；安装程序实际静默安装、组件启动与卸载验证。
